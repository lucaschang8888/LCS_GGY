01

LCS 是什麼？先把演算法講懂

LCS 全名是 Longest Common Subsequence，中文是「最長共同子序列」。給兩個序列，我們要找出一個同時出現在兩者中、順序不變，而且長度最長的子序列。

Subsequence：可以跳著選

例如 ABCBDAB 可以選出 BCBA。中間可以跳過字元，但 B → C → B → A 的相對順序不能改變。

BCBA

不是 Substring

Substring 要求連續；Subsequence 不要求連續。LCS 要處理的是後者，所以不能只找最長連續區段。

一句話：可以跳過，但不能亂掉順序。

一個最直觀的例子

A
ABCBDAB
↔
B
BDCABA

重點不是「哪些字出現過」，而是「能不能按照相同順序挑出最長的一串」。

02

LCS 為什麼可以用 DP？

狀態：dp[i][j]

dp[i][j] = A 的前 i 個元素與 B 的前 j 個元素的 LCS 長度。

我們不是一次解完整個問題，而是先解很多「前綴」的小問題，再把答案組合起來。

兩種情況

相同：最後兩個元素可以一起加入答案。
不同：最後兩個元素不能同時配對，要嘗試跳過其中一個。

相同
A[i-1] == B[j-1]
dp[i][j] = dp[i-1][j-1] + 1。因為這兩個元素可以成為 LCS 的最後一個元素。
不同
A[i-1] != B[j-1]
dp[i][j] = max(dp[i-1][j], dp[i][j-1])。分別嘗試跳過 A 的最後元素或 B 的最後元素。
邊界
i = 0 或 j = 0
其中一邊是空序列，沒有共同元素，所以 LCS = 0。
到這裡先記住：「相同 → 左上角 + 1；不同 → 上面和左邊取最大」。這就是 LCS DP 的核心。

UVa 531 的 Input / Output

INPUT RULE
test case 1：第一段文字 test case 1：第二段文字 # test case 2：第一段文字 test case 2：第二段文字 # ... EOF

每一段文字由小寫單字組成，以空白分隔；一行只有 # 時，代表這一段文字結束。整個輸入以 EOF 結束。

每組測資輸出一行 最長共同單字子序列

長度限制

每個 word 少於 30 個字元。

每段文字

少於 100 個 words。

保證

每段文字至少有一個共同 word。

官方題目明確要求以 # 結束每段文字，整份輸入則以 EOF 結束。

06

在 UVa 531 裡，dp[i][j] 代表什麼？

狀態定義

dp[i][j]
代表 Text A 的前 i 個 words，與 Text B 的前 j 個 words，所能得到的 LCS 長度。

這句話是整份程式最重要的註解。只要講清楚它，後面的兩個轉移式就很好理解。

為什麼需要二維表？

因為每個位置都同時受到「A 用到哪裡」和「B 用到哪裡」影響。兩個 prefix 的組合就是一個子問題。

CASE 1
相同
A[i-1] == B[j-1]
兩個最後 word 相同，可以把它接到左上角的最佳答案後面：
dp[i][j] = dp[i-1][j-1] + 1
CASE 2
不同
A[i-1] != B[j-1]
最後兩個 word 不能同時加入，因此比較「不使用 A 的最後 word」與「不使用 B 的最後 word」：
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
BASE
i = 0 或 j = 0
其中一段沒有 word，LCS 長度就是 0。

08

C++：把動畫翻成程式

這份程式的核心不是很長，但有兩個容易講錯的地方：第一，輸入不是一行一組；第二，最後不能只印 dp[n][m]，因為題目要的是實際的 word 序列。

UVa 531 · C++17讀入 → DP → 回溯 → 輸出
// UVa 531 - Compromise #include <bits/stdc++.h> using namespace std; int main() { ios::sync_with_stdio(false); cin.tie(nullptr); vector<string> A, B; string word; // 一組測資：讀到第一個 # while (cin >> word) { A.clear(); B.clear(); while (word != "#") { A.push_back(word); cin >> word; } // 再讀第二段文字，直到第二個 # while (cin >> word && word != "#") { B.push_back(word); } int n = A.size(), m = B.size(); vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0)); // 1. 建立 LCS 長度表 for (int i = 1; i <= n; ++i) { for (int j = 1; j <= m; ++j) { if (A[i - 1] == B[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1; else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]); } } // 2. 從右下角回溯，找出真正的答案 vector<string> ans; int i = n, j = m; while (i > 0 && j > 0) { if (A[i - 1] == B[j - 1]) { ans.push_back(A[i - 1]); --i; --j; } else if (dp[i - 1][j] >= dp[i][j - 1]) { --i; } else { --j; } } reverse(ans.begin(), ans.end()); for (int k = 0; k < (int)ans.size(); ++k) { if (k) cout << ' '; cout << ans[k]; } cout << '\n'; } }
① Input讀兩段 word，遇到 # 結束。
② DP相同走左上，不同取上／左最大。
③ Backtracking從右下角找回真正的答案。
09

最後一步：為什麼還要回溯？

DP 表告訴我們「多長」

dp[n][m] 是最長共同子序列的長度。例如答案長度是 4，但單看這個數字，你還不知道是哪四個 words。

回溯才找回「哪四個」

從右下角開始。如果兩個 word 相同，就選它並斜走；如果不同，就往 DP 值比較大的方向走。

上台可以這樣講

① 「我們先用 DP 算出每個 prefix 的 LCS 長度。」
② 「所以右下角知道最長答案有多長，但還沒有把單字存成答案。」
③ 「接著從右下角倒著走，遇到相同 word 就代表它是答案的一部分。」
④ 「因為我們是倒著找到答案，所以最後 reverse 一次，才是正確順序。」
注意：當上方與左方 DP 值相同時，可以選其中一邊。題目允許多個最長共同子序列，所以不需要唯一答案。
